Команды игрокам

ClientCommandHandler — открывается по нажатию [ё], вводится через точку

i
Команды прописываются в ClientCommandHandler и доступны любому игроку. Открываете по нажатию [ё], вводите точку и слитно команду. Пример: .cuff

rskinСменить одежду. Работает если включена ИМ.
hitУдарить игрока. Отключена

Команды (через RA-панель)

newrole [id] [название] [ивент]Создаёт роль. ID игрока, с которого создаётся роль, ивент — к которому относится. Спавните игрока, выдаёте предметы, dummy, size, setname — всё сохранится.
delrole [имя] [ивент]Удалить роль.
addcategory [имя] [роль1, роль2, ...]Перенести роли в категорию. Например, сделать отряд МОГ Epsilon-11.
delcategory [имя] [ивент]Удалить категорию целиком.
listrole / listrole 2 / listrole ГородСписок ролей. Просто список, по номеру страницы или по названию ивента.
chorole [имя] [ивент]Выбрать роль/категорию для бинда.
giverole [имя] [ивент]Выдать роль тому, на кого смотришь, без бинда.

Бинды

i
Server Specific Settings → «Выдача роли». Назначайте на клавиши, которые в бою случайно не нажмёте.
Вкл/Выкл менюГлавный переключатель. Без него ничего не работает (защита от случайных нажатий).
Prev/Next ивентЛистают ивенты.
Prev/Next рольЛистают роли.
Выбрать рольЗапоминает текущую роль.
Выдать рольВыдаёт роль тому, на кого смотришь.

Как раздавать на ивенте

01Жмёшь Вкл/Выкл меню — появится зелёный Меню: ВКЛ.
02Стрелками находишь нужный ивент и роль.
03Выбрать роль — увидишь Выбрано: Бункер → МОГ.
04Смотришь на игрока, жмёшь Выдать роль — он мгновенно превращается.
05Закончил — снова Вкл/Выкл меню (выключил, чтобы случайно не выдать).

Категории

Категория = несколько ролей в одной группе. Каждое «Выдать» в категории выдаёт следующую роль по порядку.

Пример: категория МОГ с ролями Капитан / Сержант / Рядовой.

  • 1-й клик → Капитан
  • 2-й клик → Сержант
  • 3-й клик → Рядовой
  • 4-й клик → опять Капитан (цикл)

Сброс — снова нажми «Выбрать» на этой же категории.

!
Важно: если игрок в GodMode, роль ему не выдастся. Одинаковые имена ролей в одном ивенте запрещены. В разных — можно.
